## Render
Imposta manualmente:
- CRM_USER
- CRM_PASSWORD

DATABASE_URL viene collegato automaticamente dal database PostgreSQL
definito nel render.yaml.

## Archivio
Apri:
https://TUO-SITO.onrender.com/crm-proposte.html

Il browser richiederà le credenziali CRM.

## Prova
1. Genera una richiesta dal telefono.
2. Apri il CRM da un altro dispositivo.
3. Verifica che la richiesta compaia.
4. Cambia stato e salva note.
5. Ricarica: i dati devono restare presenti.

L'invio WhatsApp automatico senza apertura dell'app richiede la
WhatsApp Business Cloud API e non è incluso nello Sprint 3.
