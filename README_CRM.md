# WTE CRM — Versione finale Sprint 3

## File da caricare nel repository
Sostituisci:
- server.js
- crm-proposte.html

Puoi caricare anche tutto il contenuto dello ZIP senza eliminare immagini, logo e firma già presenti.

## Accesso archivio
Dopo il deploy apri:

https://wedding-book-ai.onrender.com/crm

In alternativa:

https://wedding-book-ai.onrender.com/archivio

Il browser richiederà:
- nome utente: valore di CRM_USER
- password: valore di CRM_PASSWORD

## Prova definitiva
1. Genera una nuova richiesta dal configuratore.
2. Apri /crm.
3. Inserisci le credenziali.
4. La richiesta deve comparire nell’elenco.
5. Aprila, cambia stato e salva una nota.
6. Ricarica la pagina: le modifiche devono restare presenti.

Il CRM è protetto e non compare nei pulsanti visibili al cliente.
